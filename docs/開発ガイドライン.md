# 開発ガイドライン
## 1. 認証
- Google認証とSpring Securityを使用する。
- Google認証はログインの入り口として使用し、その後の認証状態の管理はSpring Securityに移譲する。
---
## 2. 技術スタック
### フロントエンド
#### CSSライブラリ
- Tailwind CSS
- shadcn/ui
#### 状態管理
- Zustand
> 現行実装では React Context (`frontend/nextjs/lib/store.tsx`) を使用しています。
#### フォーム状態管理
- React Hook Form
> 現行実装ではコンポーネント内 state とサーバーサイドバリデーションを使用しています。
#### データフェッチ
- TanStack Query（React Query）
- SWRも選択肢とする
> 現行実装では API クライアント (`frontend/nextjs/lib/api.ts`) と Context の再取得処理を使用しています。
### バックエンド
#### フレームワーク
- Spring Boot
- Java
#### データベース
- MySQL
#### ORM / 永続化
- Spring Data JPA
- Hibernate
### コードアーキテクチャ
- レイヤードアーキテクチャを採用する。
- 主に以下の層へ責務を分離する。
  - Controller
  - Service
  - Repository
### デプロイ先
- AWS EC2
