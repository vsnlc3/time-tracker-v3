## 4. 読むときのポイント

最初から `components/ui` の細部へ入らない。まず `page.tsx` -> `AppShell` -> `StoreProvider` -> `api.ts` の順で、画面がどのようにデータへ到達するかを掴む。その後、同じ操作を `Controller` -> `Service` -> `Repository` -> `Entity` -> `schema.sql` の順に追うと、UIライブラリの細部に引っ張られずに理解できる。
